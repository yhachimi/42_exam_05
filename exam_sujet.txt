2. String Compression and Decompression

Description:
Implement two functions:
- Compress: Given a string, replace consecutive repeated characters with the character followed by its count (e.g., "aaabccdddd" → "a3bc2d4").
- Decompress: Given a compressed string, reconstruct the original string (e.g., "a3bc2d4" → "aaabccdddd"). Counts may consist of multiple digits.

LeetCode:
- String Compression (Compression only): https://leetcode.com/problems/string-compression/
- No official LeetCode equivalent for decompression.


3. Word Ladder

Description:
Given a begin word, an end word, and a dictionary of valid words, find the length of the shortest transformation sequence from the begin word to the end word. Each transformation changes exactly one character, and every intermediate word must exist in the dictionary. Return 0 if no valid transformation exists.

LeetCode:
https://leetcode.com/problems/word-ladder/
